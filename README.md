# Legend

The app's vision: [VISION.md](VISION.md).

A coin and banknote collecting app: photograph a coin or a bill, the factory's grist names it, and it joins a private collection you can search, learn from and show on a globe. Built for Paul; made for any collector.

The legend is the inscription around a coin. This is the inscription around his.

Served at https://legend.allmymind.org. Licence-gated through [bsv-kit](https://github.com/Jonathan-A-White/bsv-kit); the tutor and the photo reader run on the factory's mill through Postern.

## Status

The walking skeleton: an installable, offline-first PWA shell with the Update banner and What's new, a home screen that names the build, and the docs a Builder reads first (`CLAUDE.md`, `docs/overview.md`, `docs/module-map.md`). The licence gate, photo-to-item grist, the collection and the demo follow; the epic is tracked in the millwright factory.

```bash
npm ci && npm run dev
```
